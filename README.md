# LEONTICS — Política de privacidad

Esta página existe para un solo fin: ser la URL pública de la política de privacidad de
**LEONTICS** que pide Google Play.

- **Español e inglés**, en la misma página.
- El juego **no pide permisos, no se conecta a internet y no recoge ningún dato**.

La fuente vive en el repositorio del juego, en `docs/tienda/politica-de-privacidad.html`.
Si cambia allí, hay que traerla aquí.
